배지 관리 매뉴얼

disa_app(임무 편집)과 twin-alarm(현장 실행)이 공유하는 배지 체계 — 무엇이 있고, 어떻게 늘리는가. 2026-07-16 기준.

01배지란 무엇인가

한 사람에게 붙는 "이번 재난에서 이 사람이 할 일" 표식입니다.

disa_app에서 재난별 역할(role)마다 배지를 지정하고 임무를 채워두면, twin-alarm에서 직원 한 명 한 명에게 그 배지를 배정하는 순간 — 재난이 발령됐을 때 그 사람 화면에 해당 임무 목록이 자동으로 뜹니다. 배지는 두 앱을 잇는 유일한 연결 고리이고, DB에는 정해진 목록이 없는 자유 문자열입니다. 아래 23종은 "현재 우리가 합의해서 쓰기로 한" 표준일 뿐, 늘리는 데 구조적 제약은 없습니다.

03번호 배지(1~4) 사용 원칙

대응/유도/지원 세 계열만 번호를 붙일 수 있습니다. 언제, 왜 나누는지 기준입니다.

언제 나누는가

한 배지에 묶을 인원이 너무 많거나, 소속 파트가 뚜렷이 갈릴 때만 나눕니다. 예를 들어 지진 대응조는 전기·건축파트와 기계·미화·주차파트가 임무 자체가 달라서 대응1 / 대응2로 쪼갰습니다. 인원이 적거나 임무가 동일하면 굳이 나누지 말고 그냥 대응을 쓰세요 — 배지가 늘어날수록 disa_app에서 관리할 역할 수도 그만큼 늘어납니다.

번호가 자동으로 연동되는 기능

조장 자동 현장처리 화재에서 출동·대응(대응1~4 포함)·구조 배지를 가진 파트장이 임무를 체크하면, 같은 조원 중 "출동중"이던 사람이 자동으로 "현장"으로 바뀝니다. 이 판정은 배지 이름의 앞글자만 보고(접두어 매칭) 인식하므로, 대응1이든 대응2든 대응99를 새로 만들어도 코드를 손댈 필요 없이 그대로 동작합니다.

04새 배지 추가하는 절차

대응3·지원3·유도3처럼 이미 목록에 있는 번호를 실제로 쓰기 시작할 때 — 코드 수정 없이 아래만 하면 됩니다.

  1. disa_app에서 새 역할 생성 재난대응메뉴얼 → 해당 재난 → 임무수정 → 새 역할 추가. 배지 드롭다운에 이미 대응1~4/유도1~4/지원1~4가 준비돼 있습니다.
  2. 임무 입력 그 조가 수행할 임무를 순서대로 채웁니다. 기존 같은 계열(예: 대응1) 역할을 복사해서 시작하면 빠릅니다.
  3. twin-alarm 관리자패널에서 인원 배정 해당 재난·근무 화면에서 새 배지를 가질 직원을 선택해 배정합니다. 한 사람은 재난+근무당 배지를 1개만 가질 수 있습니다(아래 5번 참고).
  4. 동작 확인 배정된 직원 계정으로 twin-alarm에 로그인해 "나의 임무"에 새 역할의 임무가 정상적으로 뜨는지 확인합니다. 훈련 발령으로 테스트하면 실제 알림 없이 확인 가능합니다.

05주의사항

이것만은 꼭
  • 직원 1명 = 재난 1개 + 근무(주/야간) 1개당 배지 1개. "대응1"이면서 동시에 "대응2"일 수 없습니다 — 조를 옮기려면 기존 배정을 지우고 새로 배정하세요.
  • 이름은 한 글자도 다르면 안 됩니다. 대응1과 대응 1(띄어쓰기 포함)은 시스템이 완전히 다른 배지로 취급합니다.
  • 색상은 배지가 아니라 역할(role)마다 따로 저장됩니다. 같은 대응1이라도 지진과 폭설에서 색이 다를 수 있습니다 — 정상입니다.
  • TTS 전화는 배지가 아니라 재난 편제표에서 사람별로 체크한 "TTS 필수" 여부로 결정됩니다(2026-07-24 변경 — 예전의 "총괄·통제·출동 자동 1차, 나머지 2차" 규칙은 삭제됨). 자세한 내용은 docs/tts-manual.html 참고.

## 1. 앱 접속 및 설치

### 접속 URL
```
https://atssa-kim.github.io/twin-alarm/
```

Chrome(Android) 또는 Safari(iOS)에서 위 주소로 접속합니다.

---

### PWA 설치 (홈 화면 추가) — 권장

앱을 홈 화면에 설치하면 알림 수신이 안정적으로 동작합니다.

**Android Chrome**
1. 앱 접속 후 상단에 표시되는 **[홈 화면에 설치]** 배너 탭
2. 배너가 없으면: Chrome 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

**iOS Safari**
1. 하단 공유 버튼(□↑) 탭
2. **홈 화면에 추가** 선택 → **추가** 탭

> 설치 후 홈 화면에서 Twin-alarm 아이콘으로 실행하세요.

## 2. 푸시 알림 설정

재난 발령 시 사이렌·진동 알림을 백그라운드에서 받으려면 알림 권한이 필요합니다.

1. 로그인 직후 상단에 **"알림 허용"** 배너가 표시됩니다.
2. **[알림 허용]** 버튼 탭 → 브라우저 팝업에서 **허용** 선택

> **알림이 차단된 경우 해제 방법**
> - Android Chrome: 주소창 왼쪽 🔒 → 사이트 설정 → 알림 → 허용
> - PC Chrome/Edge: 주소창 왼쪽 🔒 → 알림 → 허용
> - 변경 후 알림 배너에서 [알림 허용] 버튼을 다시 탭

## 3. 로그인

1. 상단 파트(부서) 탭에서 본인 소속 탭 선택
2. 목록에서 본인 이름 선택
3. 비밀번호 입력 후 **[로그인]**

| 탭 | 포함 인원 |
|---|---|
| 상황실 | 교대 방재직원 (로그인 시 지휘/발령 화면으로 이동) |
| 교대근무자 | 전체 교대 직원 (로그인 시 임무 화면으로 이동) |
| 기계파트 ~ 미화파트 | 각 파트 소속 직원 |

> 로그인 정보는 기기에 저장되므로 다음 접속 시 자동 로그인됩니다.
> 로그아웃하려면 우측 상단 로그아웃 버튼(→) 탭.

## 5. 지휘관 — 상황 발령

### 5-1. 발령 화면 진입

지휘관 로그인 시 자동으로 **[지휘관]** 탭이 열립니다.
발령된 상황이 없으면 **신규 비상 상황 발령** 폼이 표시됩니다.

---

### 5-2. 발령 절차

**① 재난 유형 선택**

| 재난 | 아이콘 |
|---|---|
| 화재 | 🔥 |
| 정전 | ⚡ |
| 누수·침수 | 💧 |
| 태풍/홍수 | 🌀 |
| 폭설 | ❄️ |
| 지진 | 🌍 |
| 가스누출 | 💨 |
| 승강기갇힘 | 🛗 |
| 테러 | 🚨 |

**② 발령 구분 선택**

- **훈련** — 실제 대피 없이 훈련 진행
- **실제** — 실제 비상 상황

**③ 화재 전용 — 발령 범위 선택**

화재 선택 시 추가 옵션이 표시됩니다:

| 옵션 | 설명 |
|---|---|
| 🔔 감지기동작 | 초기출동조(총괄·상황실·통제·출동 배지)만 먼저 소집 |
| 🚒 전체 화재 | 전체 대원 동시 소집 |

**④ 발생 위치 입력**
- 예: `B동 3층 기계실`, `지하 1층 주차장`

**⑤ 훈련 참여인원 선택 (훈련 모드일 때만)**

훈련 시 실제 참여 인원만 선택해야 해당 인원에게만 알람이 발송됩니다.
- 파트별 탭에서 개별 또는 팀 단위로 선택
- 우측 카운트로 선택 현황 확인

**⑥ 즉시 비상 발령 버튼 탭**

```
즉시 비상 발령 (사이렌/임무 생성)
```

발령 즉시:
- 선택된 대원 전원에게 **FCM 푸시 알림** 발송
- 앱 내 **TTS 육성 경보** 재생
- **카카오 알림톡** 발송 (설정된 경우)
- 각 대원별 **임무 체크리스트** 자동 생성

---

### 5-3. TTS 화자 변경

발령 폼 우측 상단 **[화자변경]** 버튼 탭 → 원하는 음성 선택
선택 즉시 "화자 변경 완료" 음성 미리듣기 재생

## 6. 지휘관 — 발령 중 모니터링

### 6-1. 발령 상태 배너

화면 상단에 현재 발령 정보(재난 유형, 장소, 모드)가 표시됩니다.
초기출동조 소집 중이면 `감지기동작` 뱃지가 함께 표시됩니다.

---

### 6-2. 업무 수행율 카드

전체 임무 중 완료된 임무 비율을 실시간으로 표시합니다.

---

### 6-3. 대원 출동 현황

헤더를 탭하면 목록을 접거나 펼칠 수 있습니다.

**대원 상태 색상**

| 색상 | 상태 | 의미 |
|---|---|---|
| 🟠 주황 | 출동중 | 현장으로 이동 중 |
| 🔵 파랑 | 현장 | 현장 도착 완료 |
| 🟢 초록 | 복귀 | 임무 완료 후 복귀 |
| ⚫ 회색 | 미응답 | 앱 미확인 상태 |

---

### 6-4. 활동 로그 (아코디언)

최근 대원 이동 및 임무 완료 내역을 최신순으로 확인합니다.

---

### 6-5. 지휘관 액션 버튼

**화재 감지기동작 발령 중 — 2차 출동 발령**

```
🎯 2차 출동 발령
```

초기출동조 소집 이후 전체 대원을 추가 소집합니다.
- 발령 전 "나머지 대원 소집 대상 선택" 패널에서 대상 인원 선택 가능
- 선택하지 않으면 나머지 전원 소집

**상황 종료**

```
■ 상황 종료 및 리셋
```

- 모든 대원 출동 현황 초기화
- 임무 체크리스트 전체 해제
- 훈련 참여인원 설정 초기화
- 재난 종료 처리

## 7. 대원 — 나의 임무 수행

### 7-1. 대기 화면 (발령 전)

발령 전에는 **재난 유형별 임무 미리보기**를 이용할 수 있습니다.

1. 재난 유형 드롭다운 선택
2. 본인 역할에 해당하는 임무 목록 확인
3. 미리보기에서 임무 체크 가능 (실제 데이터에 반영되지 않음)

---

### 7-2. 발령 후 임무 화면

발령이 시작되면 자동으로 본인의 임무 체크리스트가 표시됩니다.

**출동 상태 변경 버튼**

화면 상단에 현재 출동 상태와 변경 버튼이 표시됩니다:

| 버튼 | 의미 |
|---|---|
| 출동중 | 현장으로 이동 시작 |
| 현장 | 현장 도착 완료 |
| 복귀 | 임무 종료 후 복귀 |

---

### 7-3. 임무 체크리스트

- 임무 항목 탭 → 완료 처리 (초록색 체크 표시)
- 그룹 헤더(◇/◆)는 탭하면 하위 항목이 펼쳐짐
- 번호(01, 02... / 01-1, 01-2...)로 순서 확인

**체크리스트 접기/펼치기**

카드 상단 헤더를 탭하면 체크리스트를 접거나 펼칠 수 있습니다.

---

## 8. 활동 로그 조회

하단 탭 **📜 활동로그** 탭에서 전체 대응 활동 내역을 시간순으로 확인합니다.

### 필터 탭

| 탭 | 표시 내용 |
|---|---|
| 전체 | 임무 완료 + 대원 이동 통합 |
| 임무완료 | 임무 체크된 항목만 (누가 어떤 임무를 완료했는지) |
| 대원이동 | 대원 출동상태 변경 이력만 |

### 로그 항목 구성

```
[시간]  [임무 / 출동중 / 현장 / 복귀]  이름 (파트)
        └ 임무 내용 (임무 탭인 경우)
```

## 9. 공동 상황판 (COP)

하단 탭 **📋 상황판** 탭에서 전체 상황을 한눈에 확인합니다.

### 표시 정보

| 항목 | 내용 |
|---|---|
| 전체 임무 완수율 | 전체 임무 중 완료 비율 (%) |
| 소집 대원 현장도착 | 현장 도착 인원 / 전체 소집 인원 |
| 조직도별 수행율 | 역할(배지)별 임무 진행 현황 |
| 최근 대응 활동 | 최신 출동·임무 완료 내역 |

### 조직도별 수행율

**[조직도별 실시간 임무 수행율]** 헤더를 탭하면 접기/펼치기 가능

- 각 역할의 배지 색상, 임무 진행 바, 완료율(%) 표시
- ✓ 표시 = 해당 역할 임무 100% 완료
- 👤 숫자 = 해당 역할에 소집된 대원 수

## 10. 자주 묻는 질문

**Q. 앱을 열었는데 경보음이 안 납니다.**

A. 처음 접속 시 화면을 한 번 탭해야 브라우저가 소리 재생을 허용합니다. 또한 기기 음소거 여부, 볼륨을 확인하세요.

---

**Q. 알림(푸시)이 오지 않습니다.**

A. 다음 순서로 확인하세요:
1. 앱에 로그인된 상태인지 확인
2. 화면 상단 "알림 허용" 배너에서 알림 허용
3. 기기 설정 → Chrome(또는 Safari) → 알림 → 허용 여부 확인
4. Android: 앱을 홈 화면에 설치(PWA)하면 백그라운드 알림이 안정적으로 수신됩니다.

---

**Q. 로그인이 안 됩니다 / 내 이름이 목록에 없습니다.**

A. 관리자에게 직원 명부 등록 여부를 확인하세요.

---

**Q. 다른 기기에서도 쓸 수 있나요?**

A. 기기마다 따로 로그인하면 독립적으로 사용 가능합니다. 로그인 정보는 각 기기의 브라우저에 저장됩니다.

---

**Q. 발령 중 다른 앱으로 전환했다가 돌아오면 경보가 또 울립니다.**

A. 앱 백그라운드에서 수신된 푸시 알림을 탭하여 앱으로 복귀한 경우에만 경보가 재생됩니다. 단순 앱 전환(탭 전환) 시에는 재생되지 않습니다.

---

**Q. 상황 종료 후 이전 임무 내역을 볼 수 있나요?**

A. 상황 종료(리셋) 시 데이터가 초기화되므로, 훈련 결과가 필요하면 종료 전 **활동 로그** 탭에서 스크린샷으로 기록해두세요.

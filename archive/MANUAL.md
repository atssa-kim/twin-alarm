# 트윈타워 재난알람 — 사용설명서

**대상**: 트윈타워 전 직원  
**접속 URL**: https://atssa-kim.github.io/twintower-ops  
**비밀번호**: 본인 휴대전화 **뒷 4자리**

---

## 1. 앱 접속 방법

### 모바일 (권장)
1. 스마트폰 브라우저(크롬 또는 사파리)에서 URL 접속
2. 홈 화면에 추가하면 앱처럼 사용 가능

| 기종 | 방법 |
|------|------|
| **iPhone (Safari)** | 하단 공유 버튼 → **홈 화면에 추가** |
| **Android (Chrome)** | 우측 상단 메뉴(⋮) → **홈 화면에 추가** |

### PC
- 브라우저에서 URL 직접 접속

---

## 2. 로그인

1. **① 부서 선택** — 드롭다운에서 본인 소속 부서를 선택합니다  
   - 상황실 소방·BMS 직원 → **상황실**  
   - 상황실 전기·운전 교대 직원 → **교대근무자**  
   - 그 외 직원 → 해당 파트 선택

2. **② 이름 선택** — 부서 선택 후 본인 이름을 선택합니다

3. **③ 비밀번호** — 본인 휴대전화 **뒷 4자리**를 입력합니다

4. **로그인** 버튼 클릭

> 비밀번호를 모를 경우 관리자(시설운영센터)에게 문의하세요.

---

## 3. 화면 구성

로그인 후 권한에 따라 아래 화면 중 하나로 이동합니다.

| 권한 | 대상 | 이동 화면 |
|------|------|-----------|
| **지휘관** | 센터장, 상황실 방재직원 | 지휘본부 |
| **대원** | 일반 직원 | 나의 임무 |

---

## 4. 지휘본부 화면 (지휘관·방재직원 전용)

### 재난 발령

1. **재난 종류** 선택 (화재 / 정전 / 누수·침수 등)
2. **발령 구분** 선택 — 실제 / 훈련
   - 훈련 선택 시: 참여 인원을 직접 선택
3. **즉시 발령** 버튼 클릭 → 전 직원에게 즉시 전파

### 대원 현황 모니터링

- 발령 후 파트별 대원의 임무 수행 현황을 실시간 확인
- **체크박스** 클릭으로 파트 전체 선택/해제
- 상단 **A조 / B조 / C조 / D조** 버튼으로 교대조 일괄 선택

### 상황 종료

- 우측 상단 **상황 종료** 버튼 클릭 → 확인 후 초기화

---

## 5. 나의 임무 화면 (일반 대원)

- 재난 발령 시 본인에게 할당된 **임무 목록**이 자동 표시됩니다
- 각 임무 완료 시 **체크박스**를 클릭하여 수행 완료 처리
- 체크 현황은 지휘본부 화면에 **실시간** 반영됩니다

---

## 6. 유의사항

- 로그인 상태는 브라우저를 닫으면 유지되지 않습니다 (매번 로그인 필요)
- 재난 발령 중 페이지를 새로고침해도 임무 현황은 유지됩니다
- 인터넷 연결이 필요합니다 (Wi-Fi 또는 모바일 데이터)
